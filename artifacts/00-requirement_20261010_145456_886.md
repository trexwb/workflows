# 项目需求：Node.js Demo 项目

## 用户原始需求
请使用 codebuddy-pipeline skill 帮我写一个 node 的 demo。

## 需求整理
开发一个 Node.js 入门级 demo 项目，要求：

1. 使用纯 Node.js（可用 npm 管理依赖），结构清晰、代码规范、注释完整，适合作为新手学习示例。
2. 至少包含一个可运行的演示功能，例如简单 HTTP 服务、CLI 工具或文件处理小工具，运行方式要有明确说明。
3. 包含 package.json（含 start / test 等常用脚本）、README.md（说明项目功能、安装与运行方式）、基本测试（可用 node 内置 test runner 或简单断言）。
4. 代码需遵循基本工程规范：目录划分（src / test 等）、错误处理、日志输出。
5. 不引入过多复杂依赖，保持 demo 简单可读。
